adev · подготовка среды и запуск пайплайна

Минимальный UI для проверки: targetSystem → окружение → готовность → пайплайн → стадия 00 → формы

1. Target system

Мнимая система, которую разрабатывает adev. GitHub-репозиторий не нужен.

2. Окружение targetSystem

Рабочая директория и модели агентов. Ключ уходит на сервер и никогда не возвращается.

3. Готовность и план

Пайплайн не стартует, пока не заданы workspace и валидный агент на каждую роль.

4. Пайплайн

Маршрут принадлежит реестру стадий; агент не выбирает следующую стадию.

5. Входная форма USER_INPUT

Сырой запрос оператора. Сохраняется как форма, чтобы входные данные стадии были полными.

6. Запуск стадии 00

Агент-аналитик читает USER_INPUT, заполняет BRD и сдаёт форму. До трёх попыток, ошибки гейтов уходят модели.
